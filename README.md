# BluUI

Unit frames, group frames, action bars, CDM, castbars, power bars, minimap, datatexts and a bunch of skins. Turn off whatever you don't want.

## Install

Copy the `BluUI` and `BluUI_Options` folders into `World of Warcraft\_retail_\Interface\AddOns`. You need both.

## Use

- `/bui` opens settings
- `/rl` reloads the UI
